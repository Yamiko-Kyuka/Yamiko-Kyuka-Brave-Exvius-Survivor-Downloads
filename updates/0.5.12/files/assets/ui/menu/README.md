# Visuels des menus — 0.5.3

`background.png` et `logo.png` sont des illustrations originales générées pour le fan game, puis simplifiées en pixel art selon la demande : palette resserrée, grandes formes, moins de textures et d’ornements. Le logo conserve sa transparence. `launcher/poster.png` est une capture de l’accueil adapté au cadre du lanceur.

La police Cinzel est fournie sous SIL Open Font License : `assets/ui/fonts/OFL.txt`. Source : dépôt officiel [google/fonts](https://github.com/google/fonts/tree/main/ofl/cinzel). Les illustrations générées d’origine restent dans `/workspace/generated_images/` et ne sont pas nécessaires au lancement.
