BRAVE EXVIUS SURVIVOR — INSTALLATEUR WINDOWS COMPLET

1. Décompressez tout le ZIP dans un dossier où vous pouvez écrire.
2. Double-cliquez Brave-Exvius-Survivor.exe.
3. Le lanceur affiche l’image du jeu et une jauge. Le moteur officiel et les
   1 226 ressources originales (environ 4,7 Go) sont téléchargés en arrière-plan.
4. Lorsque l’installation est vérifiée, cliquez sur JOUER. Gardez le lanceur
   ouvert pendant la partie ; le jeu s’ouvre dans sa propre fenêtre Windows.
   Aucun onglet ou barre d’adresse. Le moteur graphique WebView2 est installé
   automatiquement depuis Microsoft s’il n’est pas déjà présent sur Windows.

Aucune console à garder ouverte. Reprise automatique après les coupures, y compris des fichiers partiels.
Le bouton RÉESSAYER reprend après une erreur. VOIR L’ERREUR affiche un message
copiable directement, sans avoir à chercher le fichier de log.
Fermer le lanceur pendant l’installation arrête le téléchargement ; les fichiers
complets et partiels sont réutilisés au prochain lancement. Installer-et-Jouer.bat et Jouer-Windows.bat ouvrent aussi
le nouveau lanceur pour compatibilité avec les installations précédentes.
Les détails techniques éventuels sont dans userdata/launcher.log.

Connexion Internet nécessaire à la première installation. En cas d’interruption,
relancez le même fichier : les téléchargements déjà validés sont réutilisés.
Aucun Python ou Node à installer manuellement. Windows 10/11 x64 avec le .NET Framework fourni par Windows.
Node et les ressources sont vérifiés par SHA-256 ; WebView2 par signature Microsoft ; TLS reste actif.

CONTENU COMPLET
Les 938 personnages et leurs ensembles d’animations sont inclus dans le catalogue.
Les images sont téléchargées puis lues depuis leurs archives. Les morceaux de
très grandes planches sont générés localement au moment où ils sont utilisés.
Ce petit ZIP n’est pas la version limitée aux poses d’attente de la version 0.1.

MISES À JOUR DEPUIS LE LANCEUR
Le lanceur vérifie les versions publiées sur le site GitHub Pages. Cliquez sur
METTRE À JOUR lorsqu’une nouvelle version est disponible. Seuls les fichiers
modifiés sont téléchargés ; les coupures se reprennent. Le lanceur redémarre
après installation. La sauvegarde, les sprites et le runtime sont conservés.
Si l’installation échoue, les fichiers précédents sont restaurés. Si nécessaire,
Brave-Exvius-Survivor-Updater.exe peut également restaurer une mise à jour
interrompue puis relancer le jeu. Une partie en cours bloque la mise à jour.

ANCIEN LANCEUR OU INSTALLATION MANUELLE
Décompressez ce ZIP dans le dossier de votre précédente installation et remplacez
les fichiers de l’application. Conservez assets/originals, assets/animation-tiles,
runtime/win-x64 et userdata. Les ressources déjà téléchargées seront réutilisées.
ZQSD / WASD / flèches : déplacement. Curseur : viser. Attaques automatiques.
Clic droit : dash vers le viseur. Molette : zoom / dézoom (50 % à 250 %).
C : forme. P ou Échap : pause. Magie active et Limit Break retirées.
Le lanceur ouvre la progression normale. Le mode développeur est optionnel.
Les cadrages de certaines variantes restent à vérifier visuellement.

Sources et empreintes : assets/download-report.json, runtime/manifest.json.
Les bibliothèques et leurs licences sont dans tools/vendor/.
